# Titanic Survival Prediction

## Machine Learning + Deep Learning Titanic Survival Prediction

---

## 1. Project Overview

The Titanic dataset is a popular dataset for learning Machine Learning,
Deep Learning, classification, and data analysis.

The objective of this project is to predict whether a passenger survived
the Titanic disaster.

The target variable is:

- `0` = Did not survive
- `1` = Survived

In this project, five Machine Learning models and two Deep Learning models
are trained and evaluated.

The models are compared using standard classification evaluation metrics.
The best-performing model based on the actual experiment results is saved
and integrated into a Streamlit application.

The complete workflow is:

```text
Data
  ↓
Data Analysis
  ↓
Data Preprocessing
  ↓
Machine Learning
  ↓
Deep Learning
  ↓
Model Evaluation
  ↓
Model Comparison
  ↓
Best Model Selection
  ↓
Model Saving
  ↓
Streamlit Application
  ↓
Passenger Survival Prediction
